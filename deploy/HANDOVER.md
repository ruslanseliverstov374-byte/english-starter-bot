## Как это работает

```
GitHub (код)  →  Render Free (бот, webhook)  →  Telegram
      ↑                    ↑                        ↑
 keepalive.yml      Render сам пингует      закреплённая копия базы
 (каждые 5 мин)        /health                 в чате владельца
```

1. **Урок дня** — повторение → новые слова → грамматика → упражнения → диалог → итоги.
2. **Повторение по интервалам** 1→2→4→8→16→32→64 дня; ошибка возвращает слово в очередь.
3. **Сохранение прогресса** — бот каждые 30 минут и после каждого урока отправляет сжатый
   снимок базы в чат владельца и закрепляет его (предыдущий удаляет, чат не мусорится).
4. **Восстановление** — после перезапуска контейнера база пустая; первое сообщение любого
   ученика заставляет бота найти закреплённую копию через `getChat` и поднять прогресс
   целиком (проверено дважды). Никаких Upstash и сторонних сервисов не нужно.
5. **Пинг** — Render сам проверяет `/health` (эксперимент: 18 минут тишины, индикатор всё
   равно «сейчас»), плюс запасной пинг через GitHub Actions каждые 5 минут.
6. **Напоминания** — в выбранное время (Руслан 12:00, Рита 09:00, Софа 20:00); если сервис
   спал, напоминание «догоняется» при пробуждении с пометкой о задержке.

## Полезные команды (из папки проекта)

```bash
python tests/check_cloud.py       # проверить сервис снаружи: health + статистика
python tests/monitor_cloud.py     # одна строка состояния
python tests/simulate.py          # полный прогон 84 дней курса (тесты)
python tests/stress.py 30 2       # нагрузочный тест: 30 учеников
python tests/test_remote.py       # тест хранилища копий
python tools/push_to_github.py    # залить изменения кода (Render пересоберёт сам)
python tools/ping_service.py      # разбудить сервис вручную
python tools/stop_bot.py          # остановить локальную копию бота
```

## Если что-то случится

| Симптом | Что делать |
|---|---|
| Прогресс «обнулился» | написать боту `/start` — он поднимет закреплённую копию |
| Копию случайно удалили | отправить боту файл `english-starter-backup.db` из чата — он восстановит базу |
| Бот молчит | открыть https://english-starter-bot.onrender.com/health; если 502 — сервис просыпается, подождать минуту |
| Не приходят напоминания | проверить `/settings` и что сервис жив; в крайнем случае `install_ping.bat` |
| Нужны обновления кода | они заливаются командой `tools/push_to_github.py` (нужен токен GitHub) |

## Что помнить про доступы

* **Токен бота** — `token.txt` в папке проекта и переменная `BOT_TOKEN` в Render (менять в двух местах).
* **Токен GitHub** (`render-deploy`) — права `Contents` и `Workflows`, **истекает через 30 дней**
  (5 октября + 30). Для заливки обновлений понадобится новый или продление срока.
  Лежит локально в `data/github_token.txt` (в репозиторий и архивы не попадает).
* **Закреплённое сообщение в чате с ботом** — это резервная копия базы. Не удаляйте его.
* **Ваш ПК** — больше не участвует в работе бота; локальная копия остановлена.
