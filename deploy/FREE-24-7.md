# Бесплатный 24/7: схема, которая реально работает

Бот живёт в облаке бесплатно, без вашего компьютера и без ежемесячных платежей.

```
GitHub (код)  →  Render Free (сам бот, webhook)  →  Telegram
                        ↑            ↓
        cron-job.org (пинг)     Upstash (снимки базы — чтобы прогресс не терялся)
```

Почему нужны все части:

| Часть | Зачем | Цена |
|---|---|---|
| **Render Free** | запускает бота, даёт публичный HTTPS-адрес для Telegram | 0 ₽, карта не нужна |
| **Пинг каждые 5 минут** | бесплатный Render засыпает через 15 минут без запросов, а спящий бот не отправит напоминание | 0 ₽ (cron-job.org или GitHub Actions) |
| **Upstash** | у бесплатного Render диск временный: перезапустили контейнер — база пропала. Снимок во внешнем хранилище возвращает прогресс автоматически | 0 ₽, карта не нужна |
| **GitHub** | откуда Render берёт код | 0 ₽ |

Если Upstash не подключать, бот всё равно работает, но после редкого перезапуска прогресс
придётся восстановить одним действием: бот пришлёт в чат запрос, а вы перешлёте ему файл
последней копии (автокопии в Telegram работают каждые 2 дня).

---

## Шаг 1. Выложить код на GitHub (5 минут)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно, карта не нужна).
2. **New repository** → имя `english-starter-bot` → **Private** или Public → **Create**.
3. На странице репозитория: **Add file → Upload files** → перетащите **все файлы** из
   архива `english-bot-github.zip` (я его подготовил; в нём нет токена и личных данных) → **Commit changes**.

## Шаг 2. Запустить на Render (5 минут)

1. Зарегистрируйтесь на [render.com](https://render.com) → **Get Started** → войдите **через GitHub**.
2. **New → Web Service** → выберите репозиторий `english-starter-bot`.
3. Настройки:
   * **Runtime**: Docker;
   * **Instance Type**: **Free**;
   * **Region**: Frankfurt (ближе к Telegram);
   * **Health Check Path**: `/health`.
4. В разделе **Environment Variables** добавьте:
   * `BOT_TOKEN` = токен от @BotFather;
   * `AUTO_BACKUP` = `1`.
   *(адрес для webhook Render подставит сам — заполнять не нужно)*
5. **Create Web Service**. Сборка занимает 2–5 минут. Когда статус станет **Live**,
   Render покажет адрес вида `https://english-starter-bot.onrender.com`.

Проверка: откройте этот адрес в браузере — увидите страницу со статистикой курса
(она же работает как health-check и годится для портфолио).

## Шаг 3. Внешнее хранилище для прогресса (рекомендуется, 5 минут)

1. Зарегистрируйтесь на [upstash.com](https://upstash.com) (бесплатно, карта не нужна).
2. **Create Database** → тип **Redis** → регион Frankfurt → **Create**.
3. На странице базы найдите **REST API**: скопируйте `UPSTASH_REDIS_REST_URL` и
   `UPSTASH_REDIS_REST_TOKEN`.
4. В Render → ваш сервис → **Environment** добавьте:
   * `SNAPSHOT_URL` = скопированный URL (без слэша в конце);
   * `SNAPSHOT_TOKEN` = скопированный токен.
5. Render перезапустит сервис. В логах появится строка
   `внешнее хранилище снимков включено`.

Теперь бот каждые 10 минут и после каждого урока складывает туда снимок базы, а при
перезапуске контейнера забирает его обратно **сам, без вашего участия**.

## Шаг 4. Пинг, чтобы сервис не засыпал (3 минуты)

**Вариант А (надёжнее): [cron-job.org](https://cron-job.org)**
1. Регистрация (бесплатно, карта не нужна) → **Create cronjob**.
2. URL: `https://ваш-сервис.onrender.com/health`
3. Расписание: **каждые 5 минут** → Save.

**Вариант Б (без сторонних сервисов): GitHub Actions** — файл
`.github/workflows/keepalive.yml` уже лежит в репозитории. Достаточно в
GitHub → Settings → Secrets and variables → Actions → **Variables** добавить
переменную `BOT_URL` = адрес сервиса Render.
Нюанс: GitHub отключает такие задачи после 60 дней без активности в репозитории,
а запуск может задержаться на несколько минут.

## Шаг 5. Выключить локальную копию

Чтобы два бота не спорили за обновления Telegram:
* если включали автозапуск — `remove_autostart.bat`;
* иначе — просто закройте окно бота, или выполните `python tools/stop_bot.py`.

## Что получится в итоге

| Что | Как |
|---|---|
| Бот работает | круглосуточно, пока живы Render и пинг |
| Ваш компьютер | можно выключать — он больше не участвует |
| Перезагрузка/передеплой Render | бот стартует сам, прогресс подтягивается из Upstash |
| Сообщения и кнопки | через webhook, отвечает мгновенно (кроме холодного старта ~30–60 с после долгого сна) |
| Напоминания | приходят в выбранное время, потому что пинг не даёт сервису уснуть |
| Резервные копии | файлом в Telegram раз в 2 дня + снимки в Upstash каждые 10 минут |
| Лимиты | Render Free: 750 часов/мес (круглосуточно = ~730, влезает), 512 МБ памяти — боту нужно ~40 МБ |

## Ограничения, о которых честно стоит знать

1. **Холодный старт.** Если пинг отключить, сервис уснёт и первое сообщение обработается
   через 30–60 секунд. С пингом этого не происходит.
2. **Аптайм бесплатного тарифа не гарантирован.** Render может перезапускать контейнеры
   (обновления платформы) — поэтому и нужен Upstash.
3. **Файлы в контейнере не сохраняются** — ничего важного вне базы мы не пишем.
4. **Публичный адрес** виден всем, но на странице только агрегированная статистика
   (число учеников и слов), личных данных нет.

## Проверка после настройки

1. Напишите боту `/start` → онбординг → урок дня доходит до конца.
2. `/progress` — прогресс на месте (он переехал вместе со снимком базы).
3. `/backup` — приходит файл базы.
4. Откройте адрес сервиса в браузере — страница статистики отвечает.
5. В Render → Logs: строки `режим webhook, адрес: ...`, `Webhook установлен: ...`,
   `внешнее хранилище снимков включено`.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| `Conflict: terminated by other getUpdates request` | где-то ещё работает копия бота (ПК или второй сервис) — остановите лишнюю |
| Бот молчит, в логах пусто | не задан `BOT_TOKEN` или сервис ещё собирается |
| Напоминания не приходят | не настроен пинг (шаг 4) — сервис спит |
| Прогресс обнулился после передеплоя | не настроены `SNAPSHOT_URL`/`SNAPSHOT_TOKEN` (шаг 3); восстановите из копии в Telegram |
| Страница `/health` отдаёт 502 | сервис просыпается, подождите минуту и обновите |

Когда всё поднимется — пришлите мне адрес сервиса, я проверю снаружи: страницу,
health-check, лог webhook и статус бота в Telegram.
