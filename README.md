# 🇬🇧 English Starter — Telegram-бот для изучения английского с нуля

Бот-репетитор: 12 недель, 84 коротких занятия по 10 минут, 360 слов, 34 грамматические
карточки, 14 диалогов и умное интервальное повторение. Уровень на выходе — A1.

Написан на чистом Python (только стандартная библиотека): **никаких установок пакетов**,
прогресс хранится в файле SQLite.

📄 Подробная программа курса: [PROGRAM.md](PROGRAM.md) · [PROGRAM.docx](PROGRAM.docx)

---

## 1. Быстрый старт (2 минуты)

1. **Получите токен бота.** В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot`
   → придумайте имя → скопируйте токен вида `8123456789:AAH...`
2. **Запустите `setup.bat`** (двойной клик). Скрипт спросит токен, сохранит его в `token.txt`,
   проверит контент курса и запустит бота.
3. **Откройте своего бота в Telegram** и нажмите `/start`. Онбординг займёт 3 нажатия:
   режим занятий, время напоминания, часовой пояс — и можно учиться.

Дальше бот каждый день в выбранное время присылает напоминание с кнопкой «Начать урок».

### Запуск вручную (без .bat)

```bash
cd english-bot
python bot.py --token 8123456789:AAH...
```

Токен можно положить в `token.txt`, в переменную окружения `BOT_TOKEN` или в файл `.env`
(образец — `.env.example`). Больше настроек не требуется: `python bot.py` и всё.

Требуется Python 3.9+ (проверено на 3.14), интернет — только исходящий.

## 2. Что умеет бот

| Команда / кнопка | Что делает |
|---|---|
| `/start` | Онбординг: режим, время напоминания, часовой пояс |
| ▶️ **Урок дня** · `/today` | Основное занятие: повторение → новые слова → грамматика → упражнения → диалог |
| 🆕 **Новые слова** · `/newwords` | Практика слов из последних уроков (закрепление до автоматизма) |
| 🧩 **Конструкции** · `/constructions` | Тренажёр грамматики: 33 конструкции, 182 задания (выбор формы, подстановка, перевод) |
| ✍️ **Практика** · `/practice` | Микс: слова последних уроков + конструкции + диалог недели |
| 📖 **Словарь** · `/dictionary` | Выученные / шаткие / закреплённые / впереди по курсу — страницами и по темам |
| 📊 **Прогресс** · `/progress` | День курса, серия дней, точность, конструкции, слабые слова |
| 📚 **Программа** · `/program` | Программа 12 недель прямо в чате |
| ⚙️ **Настройки** · `/settings` | Напоминание, часовой пояс, объём практики, перенос дня курса, сброс |
| `/review` | Только карточки слов из очереди повторения (5–10 минут) |
| `/quiz` | Быстрый тест: 10 случайных вопросов по пройденному |
| `/words` · `/word hello` | Слова по темам · карточка слова с кнопкой произношения |
| `/grammar` | Справочник грамматики: все 34 карточки |
| `/stop` · `/help` | Выключить напоминания · инструкция |

**Меню внизу экрана — 8 постоянных кнопок:**

```
[ ▶️ Урок дня ]      [ 🆕 Новые слова ]
[ 🧩 Конструкции ]   [ ✍️ Практика ]
[ 📖 Словарь ]       [ 📊 Прогресс ]
[ 📚 Программа ]     [ ⚙️ Настройки ]
```

**Как проходит урок:** повторение (5 карточек) → 5–6 новых слов с транскрипцией и примером →
грамматическая карточка → 4 упражнения (кнопки + ввод текстом) → диалог дня → итоги и серия дней.
Каждый 7-й день — повторение и тест недели. 12-я неделя — итоговое повторение и экзамен A1.

**Что внутри упражнений:** выбор перевода (в обе стороны), чтение транскрипции, пропущенное
слово в предложении, порядок слов, ввод английского слова текстом, перевод на русский текстом,
проверка грамматики. Ввод текста прощает регистр, знаки и одну опечатку.

**Повторение:** интервалы 1 → 2 → 4 → 8 → 16 → 32 → 64 дня. «Не помню» возвращает слово
в очередь, ошибка в упражнении тоже.

## 4. Запуск 24/7

### Бесплатно: Render Free + пинг + снимки базы (для личных проектов и портфолио)

Бот работает круглосуточно без вашего компьютера и без платежей:
**GitHub (код) → Render Free (webhook) → Telegram**. Пинг каждые 5 минут не даёт сервису
заснуть, а автоматические снимки базы во внешнем бесплатном key-value (Upstash) возвращают
прогресс после перезапуска контейнера — без участия человека.

Пошагово: **[deploy/FREE-24-7.md](deploy/FREE-24-7.md)**.
Архив для загрузки на GitHub собирается командой `python tools/make_github_zip.py`
(токенов, ключей и баз в нём нет — проверено).

Бонус: у сервиса появляется публичная страница со статистикой курса (она же health-check) —
её удобно показывать в портфолио.

### Платно: VPS с постоянным диском

| Вариант | Цена | Комментарий |
|---|---|---|
| **Свой ПК** | **0 ₽** | двойной клик по `install_autostart.bat`: автозапуск при входе + сторож каждые 5 минут. Работает, пока ПК включён и не спит |
| **VPS, 1 ядро / 1 ГБ** (Timeweb Cloud, FirstVDS, VDSina, Aeza) | **150–300 ₽/мес** | круглосуточно, свой диск. Установка одной командой ниже |
| **Hetzner / DigitalOcean** | 350–450 ₽/мес | то же, нужна зарубежная карта |
| **Render Starter + диск** | ~650 ₽/мес | совсем без администрирования |
| **Oracle Cloud Always Free** | **0 ₽ навсегда** | нужна карта для регистрации, бывают отказы |

**Установка на VPS одной командой** (PowerShell в папке проекта):

```powershell
powershell -ExecutionPolicy Bypass -File deploy\deploy_to_vps.ps1 -Server <IP_СЕРВЕРА>
```

Скрипт соберёт архив, сделает снимок базы (прогресс переедет), установит бота как systemd-сервис
с автозапуском, самопроверкой каждые 5 минут и ежедневной резервной копией в Telegram.
После этого выполните `remove_autostart.bat` на ПК, чтобы два бота не мешали друг другу.

Подробности, вариант с Docker, Render и решение проблем: [deploy/DEPLOY.md](deploy/DEPLOY.md)

**Прогресс в безопасности:** `/backup` присылает файл базы в чат владельца, автоматические копии —
раз в 2 дня (на VPS — ежедневно в 20:00), плюс снимки во внешнее хранилище каждые 10 минут,
если заданы `SNAPSHOT_URL` и `SNAPSHOT_TOKEN`. Восстановить вручную — отправить файл боту.

## 5. Проверка и обслуживание

```bash
python bot.py --check        # целостность контента курса
python tests/simulate.py     # полный прогон 84 дней виртуальным учеником (без Telegram)
python tests/stress.py 30 2  # нагрузочный тест: 30 учеников, 2 дня занятий
python tools/make_program.py --docx   # пересобрать программу курса
```

`tests/simulate.py` — главный тест: он проходит весь курс от `/start` до экзамена A1,
проверяет план каждого дня, все команды, напоминания и точность ответов.

### Сколько выдержит (замерено нагрузочным тестом, не оценка)

| Учеников | Память бота | База за полный курс | Процессор | Ошибок в тесте |
|---|---|---|---|---|
| 2 (сейчас) | **40 МБ** | 124 КБ | простаивает | 0 |
| 30 | ~40–45 МБ | ~2–9 МБ | 55 с за весь курс | 0 |
| 100 | ~40 МБ | ~10–30 МБ | — | 0 |
| 300 | 55 МБ | ~20–90 МБ | 16 с на 15 600 действий | 0 |

Один урок = **22 мс процессора** и ~34 сообщения. Локально бот переваривает ~1000 действий в
секунду, поэтому узкое место — не память и не процессор, а лимиты Telegram (~30 сообщений/с на
бота, ~1 сообщение/с в один чат). Самый дешёвый VPS (1 ядро, 1 ГБ) закрывает **несколько сотен**
учеников; при 1000+ одновременно активных понадобится пул воркеров и внешнее хранилище состояния —
сейчас обновления обрабатываются одним потоком.

Состояние ученика живёт в SQLite (не в памяти), контент курса загружается один раз (360 слов),
поэтому 30 учеников почти не дороже двух. Для скорости записи включены `WAL` и
`synchronous=NORMAL` — на нагрузочном тесте это ускорило коммиты примерно в 20 раз.

**Перенос прогресса** — скопируйте файл `data/bot.db` или используйте `/backup`.
**Сброс прогресса ученика** — `/settings` → «Сбросить прогресс».
**Логи** — `logs/bot.log`, `logs/watchdog.log`.

## 6. Частые вопросы

**Бот не отвечает.** Проверьте, что окно с `run.bat` открыто и в `logs/bot.log` нет ошибок
`Unauthorized` (это значит, что токен неверный — запустите `setup.bat` снова).

**Пропустил неделю, курс сгорел?** Нет. День курса не двигается без занятия, а накопленные
слова ждут в очереди повторения. Можно продолжить с того же дня или переключить день
вручную: `/settings` → «Перейти на другой день курса».

**Хочу заниматься быстрее.** `/settings` → «Объём в день»: 20 или 40 минут. Программа
курса та же, больше повторения и практики в каждом уроке.

**Можно ли учить вдвоём?** Да, бот многопользовательский: прогресс каждого ученика
хранится отдельно, напоминания приходят каждому в своё время.

**Нужен ли интернет на сервере?** Да, бот общается с `api.telegram.org` (исходящие
запросы). Входящие порты нужны только в webhook-режиме.

**Как добавить свои слова?** Допишите их в `content/words*.py` в нужную тему и запустите
`python bot.py --check` — встроенная проверка сообщит о дубликатах и пропусках.
